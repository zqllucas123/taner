# 地摊小微商户线上小店小程序 - 数据库设计文档

> 配套文档：[架构设计文档](./地摊小微商户线上小店小程序-架构设计文档.md)
> 数据库：MySQL 8.0（InnoDB / utf8mb4）+ Redis（缓存与实时状态）

---

## 一、设计约定

### 1.1 通用规范

| 项目 | 约定 |
| ---- | ---- |
| 存储引擎 | InnoDB（支持事务、外键、行锁） |
| 字符集 | `utf8mb4` / `utf8mb4_0900_ai_ci`（支持 emoji，商品图标大量使用 emoji） |
| 主键 | `VARCHAR(32)`，应用层生成（雪花/ULID/nanoid），避免分库分表迁移成本，且不暴露自增量 |
| 金额 | `DECIMAL(10,2)`，单位元；严禁用 `FLOAT/DOUBLE` |
| 经纬度 | `DECIMAL(10,7)`（约 1cm 精度） |
| 时间 | `created_at` / `updated_at`，`TIMESTAMP DEFAULT CURRENT_TIMESTAMP`；`updated_at` 带 `ON UPDATE` |
| 软删除 | 重要业务表使用 `deleted_at TIMESTAMP NULL`，查询默认过滤 `deleted_at IS NULL` |
| 外键 | 逻辑外键为主（应用层维护），不强依赖物理 `FOREIGN KEY`，便于分库与高并发写入 |
| 枚举 | 状态字段统一用 `ENUM`，避免魔法数字；新增值需评估兼容 |
| JSON | 标签、图片数组、AI 结构化结果等弱结构数据用 `JSON` 类型 |

### 1.2 公共字段（所有业务表）

```sql
created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
updated_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
deleted_at  TIMESTAMP   NULL DEFAULT NULL          -- 仅核心业务表
```

### 1.3 命名规范

- 表名：小写复数下划线（`group_buys`、`user_coupons`）
- 字段名：小写下划线（`stall_id`、`pay_amount`）
- 索引名：`idx_<字段>`、唯一索引 `uk_<字段>`、组合索引 `idx_<字段1>_<字段2>`

### 1.4 开发阶段标记

每张表标注所属阶段，与架构文档「分阶段开发计划」对齐：

- 🟢 **P1（一期 MVP）**：核心闭环 + 差异化刚需
- 🟡 **P2（二期）**：AI 深度赋能 + 社交裂变
- 🔵 **P3（三期）**：生态扩展

## 二、领域划分与实体关系总览

数据库按业务域拆分为 7 个领域：

| 领域 | 核心表 | 说明 |
| ---- | ------ | ---- |
| 用户与会员 | `users` `member_profiles` `point_transactions` | 身份、会员等级、积分 |
| 摊位 | `stalls` `stall_schedules` `stall_media` `stall_qrcodes` `stall_certs` `markets` `market_stalls` | 摊位主体、出摊时段、实景、聚合码、资质、市集 |
| 商品 | `products` `pricing_records` `inventory_logs` | 商品、AI 定价、库存流水 |
| 交易 | `orders` `order_items` `payments` `withdrawals` `ledgers` | 订单、支付、提现、台账 |
| 营销 | `coupons` `user_coupons` `group_buys` `group_buy_participants` `flash_sales` `referrals` | 优惠券、拼团、秒杀、分销 |
| 互动 | `wishes` `checkins` `checkin_likes` `notifications` | 许愿池、打卡种草、消息通知 |
| AI | `ai_voice_logs` `ai_conversations` | 语音指令、AI 客服会话 |

## 三、用户与会员域

### 3.1 用户表 `users` 🟢 P1

```sql
CREATE TABLE users (
  id            VARCHAR(32)  PRIMARY KEY,
  openid        VARCHAR(64)  NOT NULL,                 -- 微信 openid
  unionid       VARCHAR(64)  NULL,                     -- 微信 unionid（多端打通预留）
  nickname      VARCHAR(64),
  avatar_url    VARCHAR(512),
  phone         VARCHAR(20),
  role          ENUM('customer','seller') NOT NULL DEFAULT 'customer', -- 当前活跃角色
  has_stall     BOOLEAN      NOT NULL DEFAULT FALSE,   -- 是否已开店（可在双角色间切换）
  status        ENUM('normal','banned') NOT NULL DEFAULT 'normal',
  last_login_at TIMESTAMP    NULL,
  created_at    TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at    TIMESTAMP    NULL DEFAULT NULL,
  UNIQUE KEY uk_openid (openid),
  KEY idx_phone (phone)
);
```

> 说明：摊主与顾客是同一套账号体系，通过 `role` 切换（UI「我的」页支持角色切换）。`has_stall` 标记是否已开店。

### 3.2 会员档案表 `member_profiles` 🟡 P2

承载 UI「我的」页的会员等级（如「Lv.3 地摊粉」）与积分余额。

```sql
CREATE TABLE member_profiles (
  user_id        VARCHAR(32)  PRIMARY KEY,             -- 与 users 1:1
  member_level   TINYINT      NOT NULL DEFAULT 1,      -- 会员等级 1~N，系统自动定级
  level_name     VARCHAR(32)  DEFAULT '地摊新客',      -- 等级称号
  points         INT          NOT NULL DEFAULT 0,      -- 当前可用积分（冗余余额，与流水核对）
  total_points   INT          NOT NULL DEFAULT 0,      -- 累计获得积分（用于定级）
  total_spend    DECIMAL(12,2) NOT NULL DEFAULT 0,     -- 累计消费金额
  updated_at     TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 3.3 积分流水表 `point_transactions` 🟡 P2

```sql
CREATE TABLE point_transactions (
  id          VARCHAR(32) PRIMARY KEY,
  user_id     VARCHAR(32) NOT NULL,
  change      INT         NOT NULL,                    -- 正数增加，负数消耗
  balance     INT         NOT NULL,                    -- 变动后余额（快照）
  source      ENUM('checkin','order','exchange','review','admin') NOT NULL, -- 打卡/消费/兑换/晒单/手动
  ref_id      VARCHAR(32) NULL,                        -- 关联业务ID（订单/打卡等）
  remark      VARCHAR(255),
  created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_user (user_id, created_at)
);
```

> 业务规则示例（来自 UI）：打卡 +50 积分；100 积分兑换 5 元优惠券。积分增减必须同时写流水 + 更新 `member_profiles.points`（同一事务）。

## 四、摊位域

### 4.1 摊位表 `stalls` 🟢 P1

```sql
CREATE TABLE stalls (
  id              VARCHAR(32)  PRIMARY KEY,
  user_id         VARCHAR(32)  NOT NULL,               -- 摊主用户ID
  name            VARCHAR(100) NOT NULL,
  owner_name      VARCHAR(64),                          -- 摊主称呼（如「周师傅」）
  category        ENUM('小吃美食','服饰饰品','生鲜果蔬','手工文创','日用杂货') NOT NULL,
  status          ENUM('active','upcoming','offline') NOT NULL DEFAULT 'offline', -- 出摊中/即将出摊/已收摊
  status_text     VARCHAR(100),                         -- 状态文案（如「正在出摊（17:30-Midnight）」）
  location_type   ENUM('fixed','mobile') NOT NULL DEFAULT 'mobile', -- 固定/流动点位
  location        VARCHAR(255),                         -- 文字地址
  latitude        DECIMAL(10,7),
  longitude       DECIMAL(10,7),
  stall_time      VARCHAR(50),                          -- 出摊时间段文案（如「17:30 - 00:30」）
  phone           VARCHAR(20),
  description     TEXT,
  announcement    TEXT,                                 -- 摊位公告
  vibe_image      VARCHAR(512),                         -- 实景原图
  vibe_image_opt  VARCHAR(512),                         -- AI 优化后实景图
  rating          DECIMAL(2,1) NOT NULL DEFAULT 5.0,
  credit_score    SMALLINT     NOT NULL DEFAULT 100,    -- 信誉分（UI 显示 99/100）
  is_hot          BOOLEAN      NOT NULL DEFAULT FALSE,
  template_style  VARCHAR(32)  DEFAULT '小吃美食',      -- 店铺装修模板
  rest_protection BOOLEAN      NOT NULL DEFAULT FALSE,  -- 歇业保护开关
  big_font_mode   BOOLEAN      NOT NULL DEFAULT FALSE,  -- 大字极简模式开关
  market_id       VARCHAR(32)  NULL,                    -- 所属市集（P3）
  created_at      TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at      TIMESTAMP    NULL DEFAULT NULL,
  KEY idx_user (user_id),
  KEY idx_location (latitude, longitude),              -- 同城距离查询
  KEY idx_status (status),
  KEY idx_category (category),
  KEY idx_market (market_id)
);
```

> 地理查询：一期用 `latitude/longitude` 矩形框 + 应用层 Haversine 计算距离。数据量增大后可升级为 MySQL `SPATIAL` 索引（`POINT` + `ST_Distance_Sphere`）。

### 4.2 出摊时段表 `stall_schedules` 🟢 P1

支持 PRD「可设置每日出摊时段，不出摊自动线上打烊」及扫街「固定每日/临时周末/夜间限时」三种标签。

```sql
CREATE TABLE stall_schedules (
  id          VARCHAR(32) PRIMARY KEY,
  stall_id    VARCHAR(32) NOT NULL,
  schedule_type ENUM('daily','weekend','night','temporary') NOT NULL DEFAULT 'daily',
  week_days   VARCHAR(20),                              -- 适用星期，如 "1,2,3,4,5"（空=每天）
  start_time  TIME        NOT NULL,                     -- 出摊开始时间
  end_time    TIME        NOT NULL,                     -- 收摊时间
  auto_offline BOOLEAN    NOT NULL DEFAULT TRUE,        -- 超时自动打烊
  effective_date DATE     NULL,                         -- 临时市集的具体日期
  created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_stall (stall_id)
);
```

### 4.3 摊位实景媒体表 `stall_media` 🟡 P2

支撑「地摊全景实景扫街」「360° 轻量化实景预览」，出摊后拍摄、收摊后自动下架。

```sql
CREATE TABLE stall_media (
  id          VARCHAR(32) PRIMARY KEY,
  stall_id    VARCHAR(32) NOT NULL,
  media_type  ENUM('image','video','panorama') NOT NULL, -- 图片/短视频/360全景
  url         VARCHAR(512) NOT NULL,
  thumb_url   VARCHAR(512),
  is_ai_enhanced BOOLEAN  NOT NULL DEFAULT FALSE,        -- 是否经 AI 去杂乱/优化
  sort_order  INT         NOT NULL DEFAULT 0,
  is_active   BOOLEAN     NOT NULL DEFAULT TRUE,         -- 收摊后置 FALSE 自动下架
  expires_at  TIMESTAMP   NULL,                          -- 过期时间（杜绝过期场景误导）
  created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_stall_active (stall_id, is_active)
);
```

### 4.4 聚合摆摊码表 `stall_qrcodes` 🟢 P1

一码多用：进店 + 加微信 + 领券 + 预定 + 查出摊时间。

```sql
CREATE TABLE stall_qrcodes (
  id          VARCHAR(32) PRIMARY KEY,
  stall_id    VARCHAR(32) NOT NULL,
  scene_value VARCHAR(64) NOT NULL,                     -- 小程序码 scene 参数
  qr_url      VARCHAR(512),                             -- 生成的码图地址（COS）
  features    JSON,                                     -- 启用的功能 ["shop","wechat","coupon","reserve","time"]
  scan_count  INT         NOT NULL DEFAULT 0,           -- 扫码次数统计
  created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_scene (scene_value),
  KEY idx_stall (stall_id)
);
```

### 4.5 摊位资质表 `stall_certs` 🟢 P1

对应 UI 食品安全证管理（证号、发证日期、有效期、状态、持证人）。

```sql
CREATE TABLE stall_certs (
  id          VARCHAR(32) PRIMARY KEY,
  stall_id    VARCHAR(32) NOT NULL,
  cert_type   ENUM('food_safety','business','health','other') NOT NULL DEFAULT 'food_safety',
  cert_no     VARCHAR(64),                              -- 证号
  holder      VARCHAR(64),                              -- 持证人
  image_url   VARCHAR(512),                             -- 证件照片
  issue_date  DATE,                                     -- 发证日期
  expiry_date DATE,                                     -- 有效期
  status      ENUM('verified','reviewing','expired','rejected') NOT NULL DEFAULT 'reviewing',
  created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  KEY idx_stall (stall_id)
);
```

### 4.6 市集/商圈表 `markets` + 关联表 `market_stalls` 🔵 P3

支撑「夜市/市集组团出摊」「市集商圈抱团」。

```sql
CREATE TABLE markets (
  id          VARCHAR(32)  PRIMARY KEY,
  name        VARCHAR(100) NOT NULL,                    -- 市集名称（如「南门观光夜市」）
  type        ENUM('daily','weekend','night') NOT NULL DEFAULT 'night',
  center_lat  DECIMAL(10,7),
  center_lng  DECIMAL(10,7),
  cover_image VARCHAR(512),
  description TEXT,
  stall_count INT          NOT NULL DEFAULT 0,          -- 入驻摊位数（冗余统计）
  created_at  TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_location (center_lat, center_lng)
);

CREATE TABLE market_stalls (
  id          VARCHAR(32) PRIMARY KEY,
  market_id   VARCHAR(32) NOT NULL,
  stall_id    VARCHAR(32) NOT NULL,
  joined_at   TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_market_stall (market_id, stall_id),
  KEY idx_stall (stall_id)
);
```

## 五、商品域

### 5.1 商品表 `products` 🟢 P1

```sql
CREATE TABLE products (
  id              VARCHAR(32)   PRIMARY KEY,
  stall_id        VARCHAR(32)   NOT NULL,
  name            VARCHAR(200)  NOT NULL,
  price           DECIMAL(10,2) NOT NULL,               -- 现价
  original_price  DECIMAL(10,2),                        -- 划线价
  cost_price      DECIMAL(10,2),                        -- 进货成本（AI 定价用）
  stock           INT           NOT NULL DEFAULT 0,
  sold_count      INT           NOT NULL DEFAULT 0,
  image_url       VARCHAR(512),                         -- 商品图（可为 emoji 占位）
  image_optimized VARCHAR(512),                         -- AI 优化后图片
  category        VARCHAR(50),                          -- 摊内自定义分类（如「经典单品」）
  tags            JSON,                                 -- ["爆款","微辣","限量"]
  description     TEXT,
  is_clearing     BOOLEAN       NOT NULL DEFAULT FALSE, -- 尾货清仓标记
  status          ENUM('on','off') NOT NULL DEFAULT 'on', -- 上架/下架
  sort_order      INT           NOT NULL DEFAULT 0,
  created_at      TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at      TIMESTAMP     NULL DEFAULT NULL,
  KEY idx_stall_status (stall_id, status),
  KEY idx_clearing (stall_id, is_clearing)
);
```

> 商品热度多维评价（销量、复购、好评、线下试购率）：一期用 `sold_count` 排序；二期可新增 `product_stats` 物化统计表或在分析层离线计算。

### 5.2 AI 定价记录表 `pricing_records` 🟢 P1

存储 AI 定价助手的输入与建议（成本、同行价、摊位费 → 建议价/引流价/清仓价/溢价/利润/保本销量）。

```sql
CREATE TABLE pricing_records (
  id              VARCHAR(32)   PRIMARY KEY,
  stall_id        VARCHAR(32)   NOT NULL,
  product_id      VARCHAR(32)   NULL,                   -- 可关联已有商品
  food_type       VARCHAR(32),                          -- 品类（生鲜/小吃/服饰，影响定价规则）
  cost_price      DECIMAL(10,2) NOT NULL,               -- 成本/进货价
  market_price    DECIMAL(10,2),                        -- 同城同行售价
  rent_price      DECIMAL(10,2),                        -- 点位租金摊销
  suggested_price DECIMAL(10,2),                        -- AI 建议零售价
  traffic_price   DECIMAL(10,2),                        -- 引流低价
  premium_price   DECIMAL(10,2),                        -- 节假日溢价
  clearance_price DECIMAL(10,2),                        -- 尾货清仓价
  margin_rate     DECIMAL(5,2),                         -- 毛利率 %
  break_even_qty  INT,                                  -- 保本销量
  ai_reasoning    TEXT,                                 -- AI 定价说明
  created_at      TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_stall (stall_id),
  KEY idx_product (product_id)
);
```

### 5.3 库存流水表 `inventory_logs` 🟡 P2

记录库存变动，支撑「销量联动扣减 + 低库存/爆单预警」。

```sql
CREATE TABLE inventory_logs (
  id          VARCHAR(32) PRIMARY KEY,
  product_id  VARCHAR(32) NOT NULL,
  change      INT         NOT NULL,                     -- 正数入库，负数出库
  stock_after INT         NOT NULL,                     -- 变动后库存
  reason      ENUM('restock','sale','reserve','clearance','manual','rollback') NOT NULL,
  ref_id      VARCHAR(32) NULL,                         -- 关联订单等
  created_at  TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_product (product_id, created_at)
);
```

> 库存预警阈值可放在 `products` 增加 `warn_stock` 字段，或配置在 Redis；低于阈值时触发通知（写 `notifications`）。

## 六、交易域

### 6.1 订单表 `orders` 🟢 P1

```sql
CREATE TABLE orders (
  id              VARCHAR(32)   PRIMARY KEY,
  order_no        VARCHAR(32)   NOT NULL,               -- 业务订单号（展示用）
  user_id         VARCHAR(32)   NOT NULL,               -- 下单顾客
  stall_id        VARCHAR(32)   NOT NULL,
  type            ENUM('reserve','groupbuy','flash_sale') NOT NULL DEFAULT 'reserve', -- 预定/拼团/秒杀
  status          ENUM('pending','confirmed','completed','cancelled','disputed') NOT NULL DEFAULT 'pending',
  channel         ENUM('online','offline') NOT NULL DEFAULT 'online', -- 线上/线下扫码
  total_amount    DECIMAL(10,2) NOT NULL,
  discount_amount DECIMAL(10,2) NOT NULL DEFAULT 0,
  pay_amount      DECIMAL(10,2) NOT NULL,
  coupon_id       VARCHAR(32)   NULL,                   -- 使用的用户优惠券
  pickup_code     VARCHAR(16),                          -- 自提取货码（如 PICK-XXXX）
  pickup_time     VARCHAR(50),                          -- 预期取货时间
  reserve_notes   VARCHAR(255),                         -- 预定备注（如「不要辣」）
  dispute_reason  TEXT,                                 -- 纠纷原因
  dispute_status  ENUM('none','open','resolved') NOT NULL DEFAULT 'none',
  penalty_amount  DECIMAL(10,2) NOT NULL DEFAULT 0,     -- 弃单违约金
  reserve_expire_at TIMESTAMP   NULL,                   -- 限时保留截止（如下单24h内可取）
  created_at      TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_order_no (order_no),
  UNIQUE KEY uk_pickup_code (pickup_code),
  KEY idx_user (user_id, created_at),
  KEY idx_stall_status (stall_id, status),
  KEY idx_status (status)
);
```

### 6.2 订单明细表 `order_items` 🟢 P1

```sql
CREATE TABLE order_items (
  id           VARCHAR(32)   PRIMARY KEY,
  order_id     VARCHAR(32)   NOT NULL,

  subtotal     DECIMAL(10,2) NOT NULL,

);
```

### 6.3 支付记录表 `payments` 🟢 P1

```sql
CREATE TABLE payments (
  id              VARCHAR(32)   PRIMARY KEY,
  order_id        VARCHAR(32)   NOT NULL,
  user_id         VARCHAR(32)   NOT NULL,
  channel         ENUM('wechat','offline_qr') NOT NULL, -- 微信支付/线下扫码
  amount          DECIMAL(10,2) NOT NULL,
```

## 十、Redis 键设计

Redis 承载热数据、实时状态与限频，键命名 `业务:子域:标识`。

| 键 | 类型 | 说明 | TTL |
| --- | --- | --- | --- |
| `stall:status:{stallId}` | String | 摊位实时出摊状态（active/upcoming/offline） | 出摊周期 |
| `stall:nearby:{geohash}` | ZSet | 同城摊位地理索引（score=距离/热度） | 5min |
| `stall:hot` | ZSet | 夜市热力/逛市榜单（真实行为打分） | 5min |
| `product:stock:{productId}` | String | 库存计数器（下单预扣，防超卖） | - |
| `coupon:stock:{couponId}` | String | 优惠券剩余量（领取原子扣减） | 至过期 |
| `groupbuy:count:{groupId}` | String | 拼团实时人数 | 至成团/过期 |
| `flashsale:stock:{flashId}` | String | 秒杀库存 | 活动期 |
| `pickup:code:{code}` | String | 取货码 → 订单映射（快速核销） | 24h |
| `ratelimit:api:{userId}` | String | 接口限频 | 1min |
| `session:{token}` | Hash | 登录态 / 微信 session_key | 7d |

> 库存/优惠券/拼团等高并发扣减统一走 Redis 原子操作（`DECR`/Lua 脚本），异步落库，避免数据库行锁热点。

## 十二、与原型 `types.ts` 的字段映射

| 原型类型 | 对应表 | 差异说明 |
| -------- | ------ | -------- |
| `Product` | `products` | `aiSuggestedPrice`/`aiReasoning` 拆到 `pricing_records` |
